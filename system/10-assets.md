# 10 · 자산 자동 로딩

코드: [`js/assets.js`](../js/assets.js)

## 동작

게임은 시작 시 자동으로 `assets/` 폴더 안을 살펴봅니다.
파일이 있으면 그것을 쓰고, 없으면 내장된 대체본(SVG 실루엣 / 음악 없음)을 씁니다.

## 초상화

- 위치: `Game/assets/portraits/<actorId>.<ext>`
- 확장자: `png`, `jpg`, `jpeg`, `webp` (이 순서로 탐색)
- 인식되는 위치: 전투 화면, 캐릭터 선택, 동료 합류 보상
- 자동: 이미지가 로딩되면 SVG/이모지가 숨겨지고 PNG로 덮어쓰입니다.

## 음악 (BGM)

- 위치: `Game/assets/music/<screen>.<ext>`
- 확장자: `mp3`, `ogg`, `wav`, `m4a`
- 인식되는 화면 이름: `title`, `character-select`, `map`, `battle`
- 자동: 화면이 바뀌면 BGM이 자동으로 전환되고 무한 반복됩니다.

## 효과음 (SFX)

- 위치: `Game/assets/sfx/<name>.<ext>`
- 호출: `playSfx('clash')` 로 트리거
- 현재 코드는 자동 트리거 지점이 없습니다 — 직접 호출 추가 필요.

## 자동재생 제한 (모바일)

브라우저는 사용자 첫 터치 전까지 자동재생을 막습니다.
`assets.js` 가 첫 클릭/터치 이벤트를 듣고 BGM 재시도합니다 — 자동.

## 캐싱

같은 파일은 한 세션 내에서 다시 요청되지 않습니다.
새 파일을 추가하면 페이지 새로고침이 필요할 수 있습니다.
