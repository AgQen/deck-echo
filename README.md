# DECK · ECHO (가제)

덱빌딩 + 로그라이크 + 라이브러리 오브 루이나식 "합" 시스템 모바일 웹 게임의 초기 골격.

## 폴더 구조

```
Game/
  index.html              ← 모든 화면(타이틀/맵/전투/모달) 단일 페이지
  start.bat / start.ps1   ← Windows에서 로컬 서버 한 번에 실행
  css/style.css
  js/
    main.js               ← 엔트리
    state.js storage.js   ← 게임 상태, 저장/불러오기
    rng.js                ← 시드 RNG
    clash.js battle.js    ← 합 해소 / 전투 진행
    data/                 ← ★ 게임 설계가 들어가는 곳 (자유롭게 편집)
      properties.js       ← 속성, 내성
      statuses.js         ← 상태이상 (자리만 마련)
      cards.js            ← 카드 정의 + 시작 덱
      characters.js       ← 플레이어블 캐릭터
      enemies.js          ← 적 정의
      maps.js             ← 어컴호러식 노드 맵
    ui/                   ← 화면별 렌더링
      common.js title.js map.js battle.js modals.js
```

## 핸드폰에서 실행하기

1. **PC가 켜져 있고 핸드폰과 같은 와이파이** 에 있는지 확인.
2. PC에서 `start.bat` (또는 `start.ps1`) 더블클릭.
3. 콘솔에 `http://192.168.x.x:8000` 같은 주소가 표시됩니다.
4. 핸드폰 브라우저 (크롬/사파리)에 그 주소를 입력.
5. 끝.

> Python이 없다면 Microsoft Store → "Python" 검색 → 설치 한 번이면 됩니다.

방화벽 안내 창이 뜨면 **개인 네트워크 허용**을 눌러주세요.

핸드폰에서 "홈 화면에 추가" 하면 앱처럼 동작합니다.

## 현재 구현되어 있는 것

- 상/중/하 세로 레이아웃 (적·합·내 정보)
- 캐릭터당 슬롯 N개, 슬롯마다 속도 굴림
- 카드 다중 액션 (`공격/반격/막기/회피`)
- 합 결의:
  - `공격 vs 공격` → 이긴 쪽 데미지
  - `공격 vs 막기` → 차이만큼 데미지
  - `공격 vs 회피` → 회피 승리 시 무피해, 패배 시 전부 받음, 동률은 회피 승리
  - `반격` → 합 없이 양쪽 주고받음 (반격측은 정신력 피해 없음)
  - `막기 승리` → 상대 정신력 피해
- 흐트러짐 (SP 0): 모든 내성 취약, 다음 한 턴 행동 불가
- 빛(비용) 시스템: 카드마다 빛 비용, 매 턴 가득 회복, 부족하면 배치 불가
- 경험치 / 레벨 (0~5): 가해·피해·흐트러짐·처치/아군사망으로 누적. 레벨업 시 최대 빛 +1 + 즉시 가득 회복
- 속도 규칙: **나의 슬롯 속도가 상대 슬롯 속도보다 빨라야만 연결 가능** (동률은 불가)
- 책장 드로우/버림더미 셔플
- 적 AI: 패턴에서 슬롯 수만큼 무작위 배치, 첫 살아있는 플레이어에게 자동 타게팅
- 어컴호러식 노드 맵 (rest/battle/elite/event/shop/boss)
- localStorage 저장 (이어하기)
- 모바일 세이프 에어리어 대응

## 아직 자리만 있는 것

- 상태이상 시스템 (출혈/떨림/보호막 자리만)
- 사건(event)/상점(shop) 인카운터 내용
- 동료 합류 시스템
- 카드 합성/제거/업그레이드
- 사운드/이펙트
- 영구 진행 (메타 프로그레션)
- 메인 스토리

## 조작 요약

- **빈 슬롯 (+) 탭** → 손패에서 카드 선택
- **카드 길게 누르기** → 손으로 되돌리기
- **카드의 액션을 탭** → 합 연결 모드 시작 → 적 액션을 탭으로 연결
  - 자기 슬롯 속도가 상대 슬롯 속도보다 **커야** 연결 가능 (동률 불가)
- **카드 우상단 `!`** → 확대 보기
- **▶ 시작** → 턴 해소 진행
- **📜** → 최근 전투 로그 토스트로 보기
