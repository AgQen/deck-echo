핵심 흐름

  • 매 턴 시작 시 빛이 가득 채워지고, 슬롯마다 속도가 굴려진다.
  • 카드를 슬롯에 배치 → 빛 소비. 연결(합) 또는 자동 타게팅으로 진행.
  • 적의 슬롯 속도가 내 슬롯 속도보다 낮을 때만 합 연결 가능.

합 지정

  • 내 카드를 누른 다음 적 카드를 누르면 합 연결 (노란 곡선).
  • 다시 내 카드를 누르면 취소.

방어 카드

  • 미연결 방어 카드는 대기한다. 들어오는 공격에 자동 반응.
  • 막기: 차이만큼 SP 데미지를 되돌림.
  • 반격: 일방적으로 맞지만 정신력은 멀쩡, 반격값만큼 되돌림.
  • 회피: 합을 이기면 무피해, 지지 않으면 다음 공격에도 재사용.

피해 결과

  • SP=0이면 흐트러짐: 다음 한 턴 행동 불가 + 모든 내성 취약.
  • 전투마다 경험치 누적 → 레벨업 시 최대 빛 +1 + 즉시 가득.

맵

  • 총 3막. 막마다 분기된 노드 진행, 끝은 보스.
  • 보스 클리어 시 레벨/XP 초기화 + 큰 보상.
  • 전투 승리 후: 골드 + 카드 1장 선택 + (엘리트/보스) 유물.
